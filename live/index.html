ABOUT THIS VIEW

Indexed footage. Visible sources.

Replay asks the team archive for moments that match a written requirement, then plays the matching segment. Captions are model-written descriptions stored with each clip. Boxes, when shown, are object-detector output for that segment.

This is not a live camera feed, not an OSHA determination, and not proof that a scene is safe. Similarity is how closely a clip matched the words, not a calibrated probability.

The local factory demo in this repository is a separate authored preview. This view does not use those example intervals.
